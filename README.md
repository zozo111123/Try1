# 🐍 משחק הנחש - Snake Game

משחק נחש קלאסי ומודרני שנכתב ב-HTML5, CSS3 ו-JavaScript טהור.

## תכונות

- 🎮 שליטה קלה עם מקשי החיצים או WASD
- 📱 תמיכה במובייל עם כפתורי חיצים על המסך
- 🏆 מעקב אחר שיא אישי (נשמר ב-LocalStorage)
- ⚡ קושי עולה - המשחק מאיץ ככל שאוספים יותר נקודות
- 🎨 עיצוב מודרני ואטרקטיבי עם אפקטים ויזואליים
- 🌐 ממשק בעברית (RTL)

## איך לשחק

1. פתח את הקובץ `index.html` בדפדפן
2. לחץ על "התחל משחק" או הקש על רווח/Enter
3. השתמש בחיצים במקלדת (או WASD) כדי לכוון את הנחש
4. אסוף תפוחים אדומים כדי לצבור נקודות
5. הימנע מפגיעה בקירות או בגוף הנחש

## כללי המשחק

- כל תפוח שווה 10 נקודות
- הנחש גדל עם כל תפוח שנאסף
- המשחק מאיץ כל 50 נקודות
- השיא האישי נשמר במכשיר שלך

## טכנולוגיות

- HTML5 Canvas לגרפיקה
- CSS3 לעיצוב ואנימציות
- Vanilla JavaScript (ללא ספריות חיצוניות)
- LocalStorage לשמירת שיא
