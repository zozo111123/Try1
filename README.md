## 🌟 מבוא

SimuVerse AI היא פלטפורמה ייחודית המאפשרת יצירת סימולציות אינטראקטיביות מבוססות בינה מלאכותית. המערכת מיועדת למחקר, הכשרה והדרכה בתחומים שונים כמו:

- הכשרה קלינית (רפואה, סיעוד, פסיכולוגיה)
- הדרכת שירות לקוחות
- אימון מנהלים
- חינוך והכשרה מקצועית

### תכונות מרכזיות

✅ **בונה סימולציות אינטואיטיבי** - יצירת תרחישים מורכבים ללא קוד
✅ **4 סוכני AI מיוחדים** - דמות, מנטור, מאמן רפלקציה ומעריך
✅ **ממשק קול מלא** - תמיכה ב-Speech-to-Text ו-Text-to-Speech
✅ **שאלונים דינמיים** - בניית שאלוני Pre/Post מותאמים אישית
✅ **משוב אוטומטי** - ניתוח AI מעמיק עם גרפים ויזואליים
✅ **שיתוף קל** - URL-based sharing ללא צורך בשרת
✅ **ניהול מחקר** - מעקב אחר נבדקים וייצוא נתונים

## 🏗️ ארכיטקטורה

המערכת בנויה כ-**Client-Side Application** טהורה, ללא צורך בשרת backend:

```
┌─────────────────────────────────────────────────┐
│              Admin Dashboard                    │
│         (index.html + app.js)                   │
│                                                 │
│  ┌────────────┐  ┌────────────┐  ┌──────────┐ │
│  │ Simulation │  │  Research  │  │  Data    │ │
│  │  Builder   │  │   Spaces   │  │ Export   │ │
│  └────────────┘  └────────────┘  └──────────┘ │
└─────────────────────────────────────────────────┘
                      │
                      │ URL Encoding (Base64)
                      ▼
┌─────────────────────────────────────────────────┐
│         Simulation Runner (runner.html)         │
│                                                 │
│  Entry → Pre-Survey → Chat → Reflection →      │
│  Post-Survey → Evaluation → Feedback            │
│                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐     │
│  │ Roleplay │  │  Mentor  │  │Reflection│     │
│  │  Agent   │  │  Agent   │  │  Agent   │     │
│  └──────────┘  └──────────┘  └──────────┘     │
│                       │                         │
│                  ┌──────────┐                  │
│                  │Evaluator │                  │
│                  │  Agent   │                  │
│                  └──────────┘                  │
└─────────────────────────────────────────────────┘
                      │
                      │ Session Data (JSON)
                      ▼
                  💾 LocalStorage
```

## 🚀 התקנה ושימוש

### דרישות מקדימות

- דפדפן מודרני (Chrome, Firefox, Edge, Safari)
- **Gemini API Key** מ-Google AI Studio ([קבל כאן](https://makersuite.google.com/app/apikey))

### התקנה מהירה

1. **פתח את `index.html`** בדפדפן:
   ```bash
   open index.html
   # או
   python -m http.server 8000
   # ואז פתח: http://localhost:8000
   ```

2. **צור סימולציה ראשונה**:
   - לחץ על "➕ יצירת סימולציה חדשה"
   - מלא את השדות (לפחות שם וה-Roleplay Prompt)
   - שמור

3. **צור מרחב מחקר**:
   - עבור ל-"🔬 מרחבי מחקר"
   - לחץ "➕ יצירת מרחב מחקר חדש"
   - בחר את הסימולציה
   - העתק את הלינק

4. **שתף ובדוק**:
   - לחץ על "🔗 בדוק" כדי לפתוח את הסימולציה
   - בעת הכניסה הראשונה, תתבקש להזין Gemini API Key

## 📖 מדריך שימוש

### יצירת סימולציה

סימולציה מורכבת מ-6 טאבים:

#### 1. כללי (General)
- **שם הסימולציה**: שם תיאורי (למשל: "ראיון עם מטופל מאתגר")
- **תיאור**: הסבר קצר על התרחיש
- **מטרות לימודיות**: מה הלומדים אמורים להשיג

#### 2. דמות (Roleplay Agent)
```
System Prompt לדוגמה:
"את רחל, בת 70, סובלת מכאבי גב כרוניים.
את חשדנית כלפי רופאים צעירים ומעדיפה טיפולים מסורתיים.
דברי בקצרה, באופן ישיר ומעט עצבני.
אם מישהו מראה אמפתיה אמיתית, התרככי מעט."
```

- **קבצי רקע**: העלה PDF/TXT עם מידע רפואי/רקע לדמות
- **קול**: בחר קול זכר/נקבה
- **סגנון דיבור**: תיאור חופשי (למשל: "Warm but cautious")

#### 3. מנטור (Mentor Agent)
```
System Prompt לדוגמה:
"אתה מדריך קליני מנוסה. עקוב אחר השיחה בין הסטודנט למטופל.
אם הסטודנט:
- שואל רק שאלות סגורות → הצע לנסות שאלה פתוחה
- מתעלם מרגשות → הזכר לשים לב למצב הרגשי
- עושה טוב → חזק אותו

תן טיפים קצרים (משפט אחד), רק כשזה ממש נדרש."
```

✅ סמן "הפעל מנטור בזמן אמת" אם רוצה טיפים במהלך השיחה

#### 4. רפלקציה (Reflection Agent)
```
System Prompt לדוגמה:
"קרא את התמליל של השיחה. אל תשפוט עדיין.
שאל את המשתמש 3-4 שאלות רפלקטיביות מעמיקות:
- איך הרגשת כשהמטופלת התעצבנה?
- מה היית משנה אם היית יכול?
- איזה רגע היה הכי מאתגר ולמה?

התמקד ברגעי מפתח ובאינטראקציות משמעותיות."
```

#### 5. הערכה (Evaluator Agent)
```
System Prompt לדוגמה:
"נתח את הביצועים על סמך הקריטריונים הבאים.
החזר JSON בפורמט:
{
  \"scores\": [
    {\"criterion\": \"אמפתיה\", \"score\": 8, \"feedback\": \"...\"}
  ],
  \"strengths\": \"...\",
  \"improvements\": \"...\",
  \"overallScore\": 85
}"
```

**קריטריוני הערכה** (JSON):
```json
[
  {
    "name": "אמפתיה",
    "weight": 2,
    "description": "יכולת להבין ולהזדהות עם רגשות המטופל"
  },
  {
    "name": "דיוק קליני",
    "weight": 1,
    "description": "דיוק בשאילת שאלות רלוונטיות"
  },
  {
    "name": "תקשורת",
    "weight": 1.5,
    "description": "בהירות ואפקטיביות בתקשורת"
  }
]
```

#### 6. שאלונים (Surveys)
- **Pre-Survey**: שאלות לפני הסימולציה (למשל: "כמה אתה מרגיש בטוח?")
- **Post-Survey**: שאלות אחרי (למשל: "עד כמה הסימולציה הייתה מועילה?")

סוגי שאלות:
- **ליקרט 1-5** או **1-10**: סולם מספרי
- **טקסט חופשי**: תשובה פתוחה
- **בחירה מרובה**: (תכונה עתידית)

## 🤖 ארכיטקטורת הסוכנים

המערכת משתמשת ב-4 סוכני AI נפרדים עם רמות הודעה שונות:

### 1. Roleplay Agent (הדמות)
**מה הוא רואה:**
- רק את ה-System Prompt שלו
- קבצי רקע שהועלו
- היסטוריית השיחה עם המשתמש

**מה הוא לא רואה:**
- טיפים של המנטור
- שאלות הרפלקציה
- קריטריוני ההערכה

**תפקיד:** לשחק את הדמות באופן מציאותי ועקבי.

### 2. Mentor Agent (המנטור)
**מה הוא רואה:**
- את כל השיחה בין המשתמש לדמות (Live)
- את מטרות הלימוד

**מה הוא לא רואה:**
- עתיד השיחה
- הציונים הסופיים

**תפקיד:** לתת טיפים קצרים בזמן אמת כאשר המשתמש זקוק להכוונה.

### 3. Reflection Agent (המאמן)
**מה הוא רואה:**
- את התמליל המלא של השיחה
- תשובות המשתמש לשאלות הרפלקציה

**מה הוא לא רואה:**
- הציונים (עדיין לא חושבו)

**תפקיד:** לעזור למשתמש להפיק לקחים באמצעות שאלות מעוררות מחשבה.

### 4. Evaluator Agent (המעריך)
**מה הוא רואה:**
- **הכל!** השיחה + הרפלקציה + הקריטריונים

**תפקיד:** לתת ציון אובייקטיבי ומשוב מפורט.

## 🔧 API ואינטגרציות

### Gemini API Integration

המערכת משתמשת ב-**Google Gemini Pro API**:

```javascript
const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent?key=${apiKey}`;

fetch(url, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    contents: [{ parts: [{ text: prompt }] }],
    generationConfig: {
      temperature: 0.9,
      maxOutputTokens: 500
    }
  })
})
```

### Speech Recognition

שימוש ב-**Web Speech API** מובנה:

```javascript
const recognition = new webkitSpeechRecognition();
recognition.lang = 'he-IL';
recognition.continuous = false;
recognition.start();
```

### Text-to-Speech

אפשרות 1: **Web Speech Synthesis** (מובנה):
```javascript
const utterance = new SpeechSynthesisUtterance(text);
utterance.lang = 'he-IL';
speechSynthesis.speak(utterance);
```

אפשרות 2: **Google Cloud TTS** (מומלץ לפרודקשן)
אפשרות 3: **ElevenLabs** (איכות גבוהה)

## 📊 ייצוא וניתוח נתונים

### ייצוא מ-Admin Dashboard

לחץ על "📥 ייצוא נתונים" כדי להוריד:
```json
{
  "simulations": [...],
  "spaces": [...],
  "exportedAt": "2026-01-17T..."
}
```

### קובץ Session (מהמשתמש)

כל משתמש יכול להוריד דוח אישי:
```json
{
  "id": "session_...",
  "user": { "name": "...", "age": 25 },
  "chatHistory": [...],
  "reflectionHistory": [...],
  "surveyAnswers": { "pre": {...}, "post": {...} },
  "evaluation": {
    "scores": [...],
    "strengths": "...",
    "improvements": "...",
    "overallScore": 85
  }
}
```

### ניתוח ב-Excel/Python

ניתן לטעון את קבצי ה-JSON ל-Excel או לנתח עם Python:

```python
import json
import pandas as pd

# טען קובץ
with open('session_123.json') as f:
    data = json.load(f)

# המרה ל-DataFrame
df = pd.DataFrame(data['evaluation']['scores'])
print(df)
```

## 🛠️ פתרון בעיות נפוצות

### הסימולציה לא נטענת
✅ בדוק שהלינק מכיל `?data=...`
✅ נסה להזין את ה-API Key שוב
✅ פתח את ה-Console (F12) ובדוק שגיאות

✅ תן הרשאות מיקרופון לדף

✅ שפר את ה-System Prompt - תן דוגמאות
✅ הוסף הקשר בקבצי רקע
✅ התאם את ה-temperature (0.7-0.9)
